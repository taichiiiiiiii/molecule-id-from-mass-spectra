# 参加・提出ルール（要約）

出典: https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/rules
最終更新: 2026-10-30

## 提出形式（必須条件）

- 提出ファイル名は **`submission.csv`**
- ヘッダー: `molecule_id,smiles`
- 行: 1 分子につき 1 行
- `smiles` は最大 25 候補、セミコロン区切り、**最も有力なものを先頭**に
- 条件: `molecule_id` 列が存在する、`smiles` 列が存在する、空値がない、
  `molecule_id` が重複しない、25 個超の候補が出ない
- これらを満たさない提出は拒否される

## 提出経路

- **Kaggle Notebook 経由のみ**で提出可能
- ノートブック実行上限: CPU / GPU とも **9 時間**
- **コンパイル時はインターネット処理無効**（Off）
- 外部データ・事前学習済みモデルは可（公開・自由に利用できるもの）
