## 4. 読み（#292 の規則に当てはめた一文）
- **型 c・e（伸びの大きい 2 型）と d は、低い層でも 95% 区間の下限が 0 を超える →「近傍の多さだけに頼っていない」。** 型 a・b は低い層の区間が 0 を含む →「0 付近」として 12/6 の判定と最終の選び方の前にリスクに記録する（関門・列は変えない）
- 補足（規則の外の記述。これで何も選ばない）:
  - 型 c には層の順の傾きがある（低 +0.097 → 高 +0.161）。近傍が多い分子ほど伸びが大きいので、隠れテストの分子が dev より近傍の少ない側に寄っていれば、型 c 相当の伸びは dev の平均（+0.094）より小さくなり得る。型 e には傾きが見えない
  - 型 a・b は型全体の伸びがもともと小さい（a +0.0149、b +0.0096）。「0 付近」はそれと合うが、原因はこの測定では切り分けていない。型 a に層の順の傾きは見えない。型 b は中の層だけ +0.0421 [+0.0083, +0.0770] で、低・高は 0 付近という単調でない形（n 82〜83 で揺れが大きい）
  - 対照の MRR は低い層ほど高い（型 c: 低 0.681・高 0.541、型 e: 低 0.651・高 0.541）。nbr_tani_mean が高い = 近い構造が多い = 似た偽物の候補も多い領域、とも読める。「近傍が多いほど簡単」ではない
- 限界:
  - nbr_tani_mean の幅は狭い（正解の行の 10〜90% 分位はおおむね 0.55〜0.75、型 b だけ 0.50〜0.96）。dev の「低い層」の上端（境 q1）は 0.60〜0.65（型 b は 0.64）、正解の行の 10% 分位でも 0.50〜0.61 あり、「類縁体がほとんど無い」分子は dev にほぼいない。隠れテストにそういう分子が多ければ、そこは dev の外挿で、この測定では分からない
  - nbr_tani_mean は「隠す規則の後に参照の残る構造」との近さで、学習の構造の近さそのもの（arXiv:2611.28096 の proximity、MassSpecGym の MCES）とは定義が違う
  - 層は 3 seed 平均の差の記述で、層の間の差の検定はしていない（事前に決めていない）
