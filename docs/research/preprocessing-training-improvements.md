## 3. 改善の候補（前処理）

各項: 仕組み ／ 証拠 ／ 当てはまるモデル ／ 費用（ローカル時間の目安） ／ リーク・再現・ライセンス ／ 1 回の測り方。共通の測り方: 5-fold の leak-free 検証（計画中）で、対照（今の版）と変更版を同じ fold・同じ seed・同じ止め方で 1 回ずつ学習し、MRR@25 の fold ごとの差の平均と 95% 区間（fold を単位にしたブートストラップ）を見る。変更は Issue に事前登録し、値は 1 つだけ（調整しない）。

### P1. 学習データを test の分布に寄せる: [2M…] を学習から外す（または別の付加イオンとして扱う）
- 仕組み: test に無い二量体の付加イオンは、前駆体の質量と断片の関係が違うので、窓の負例との区別を別の規則で覚えさせる。外せば容量を test の付加イオンに使う。
- 証拠: データの数（§2、確認）。効果は未測定。
- 当てはまる: 3 本すべて（特に fragnn は担い手の表を付加イオンで変える）。
- 費用: 前処理の 1 行。学習は対照と同じ（fragnn 10 h 上限、整列 数 h、FPNet 4 h × fold）。
- リーク・再現: 外部データ無し。
- 測り方: 学習の行の選び方だけを変え、検証は同じ test 型の付加イオンだけで測る。

### P2. ピークの本数を test のピーク数に合わせて増やす（fragnn 32 → 64、FPNet は据え置き）
- 仕組み: 断片の説明の特徴は「説明できたピーク」の数と強度に依る。弱いピークほど小さな断片（構造の区別に効く）であることが多い（**主張**、MIST の部分式の付与で弱いピークも使う設計）。
- 証拠: test の中央値 230 本（確認）。効果は未測定。
- 費用: 前計算と 1 ステップがほぼ倍（fragnn は 20 h 近くになる恐れ。上限 96 h の規則の範囲か Issue で先に確かめる）。
- 注意: 値を 64 と 1 つに決めて事前登録する（32/48/64 を比べるのは調整になる）。

### P3. CE の欠測の印（fragnn・整列）
- 仕組み: 欠測を 0 eV と区別する 1 ビット（FPNet の `ce_known` と同じ形）。test は欠測 0% なので、学習の 13% の行の CE の誤った値が効き方を汚すのを止める。
- 証拠: FPNet が既にこの形（確認）。効果は未測定。
- 費用: 入力 1 次元。対照と同じ学習時間。

### P4. 同じ分子の複数 CE のスペクトルを merge した入力で学習・推論（fragnn・整列）
- 仕組み: test は 1 分子に 1〜16 本（中央値 3）、提出は分子に 1 リスト。今の fragnn・整列はスペクトルごとの点を後で平均する。FPNet のように学習で同じ (構造, mode) の数本を merge（確率 p）すれば、test の推論の形（分子の merge）と学習が揃う。
- 証拠: FPNet の `item` の merge_p 0.3（確認）。FPNet でその寄与を分けた測りは無い（未確認）。
- 費用: fragnn は断片の説明を merge したピークで作り直すので前計算が増える（中）。整列は DreaMS の埋め込みを merge したスペクトルで作り直す必要があり、凍結の埋め込みの作り直し（数 h）。
- 注意: p は FPNet と同じ 0.3 を借りる（新しい値を選ばない）。

### P5. 前駆体と前駆体より上のピークの扱いを揃える
- 仕組み: fragnn は前駆体の近くのピークを除かない。上位 32 本だと前駆体（とその同位体）が 1 本を取る。前駆体 − 0.5 Da より上を除く（FPNet は +2 Da まで残す）。
- 証拠: 一般的な前処理（MassSpecGym・DreaMS も前駆体を別扱い、**主張・未確認**）。効果は小さいと見る。
- 費用: 前処理の数行。P2 と一緒の Issue にすると変更が 2 つになり分けられないので、するなら別の回。

### P6. 部分式の付与（MIST 型）で断片の説明を式に制約する
- 仕組み: 前駆体の式（候補の式）の部分式だけを断片の候補にし、各ピークに式を付ける。fragnn は既に候補の構造から断片を列挙して tol 0.005 Da で当てている（構造に依る説明）。部分式の付与は構造に依らない層で、異性体の区別には効かない（同じ式の候補では同じ）。
- 証拠: MIST（出典 1、主張）。異性体の窓（同じ式が多い）では効かないのは式の定義から（確認）。
- 判断: fragnn・FPNet の主な仕事（±10 ppm の窓の中の順位）には効きにくい。**勧めない**（§6）。

### P7. 強度の変換（sqrt / log / rank）
- 今: FPNet は sqrt、fragnn は強度を使う特徴が少ない。変換を変える根拠は弱く、値を選ぶことが調整に近い。**勧めない**（§6）。m/z の binning も、3 本とも既に集合（ピークの並び）か埋め込みなので、ビンへの移行は後退。

### P8. 装置・ノイズの差（timsTOF vs Orbitrap/QTOF）
- 仕組み: (a) 装置の種類を入力に入れる（推論は常に timsTOF）、(b) timsTOF（enveda-180）を学習で多めに引く、(c) DANN 型の装置の判別器を逆勾配で（出典 7）。
- 証拠: test が 100% timsTOF、train の timsTOF は 45.5% でほぼ 1 つのライブラリ（確認）。(c) は小さなデータでは不安定になりやすい（一般論、未確認）。
- 推し: (a) の「装置の印」を入力に 1 つ（timsTOF か否か）。構造の変更で値の選択が無い。(b) は抽出の比率を選ぶことになるので避ける。
- 注意: enveda-180 は構造の重なりが大きいので、fold の分け方が構造単位であることを確かめる（既に fold-safe の前提）。

## 4. 改善の候補（学習方法）

### T1. 拡張（ピーク dropout・強度の揺らぎ・m/z の揺らぎ・同じ分子の混合）を整列と fragnn に入れる
- 今: FPNet だけが拡張あり（確認）。整列は埋め込みが凍結なので、入力の拡張は埋め込みを作り直さないと効かない（1 本につき 1 埋め込み）。fragnn は特徴の前計算が重く、拡張ごとに作り直すのは費用が大きい。
- 判断: fragnn はピークの部分集合を前計算から選び直すだけの dropout（特徴を再計算しない、ピーク単位の mask）なら安い。値は FPNet の U(0, 0.3) を借りる。
- 証拠: FPNet の採用（確認）、効果の分離は無い（未確認）。

### T2. 負例の作り方: 同じ式（異性体）を優先する hard negative
- 既存の isomer-negatives.md で扱い済み。繰り返さない。差分だけ: FPNet は「窓が 8 未満ならランダムの負例を半分」（`negatives` 115–118 行、確認）で、窓が小さい分子では容易な負例が混ざる。fragnn・整列には同じ規則が無い（窓の全部）。

### T3. 損失
- fragnn: softmax CE（listwise）。整列: InfoNCE（温度の学習）。FPNet: ranking CE + BCE + 元素数。focal BCE や cosine の損失に替える根拠は、MRR@25 の目的には listwise CE が既に合っている（objective-mismatch.md）。**勧めない**。
- 窓の大きさの違いへの較正（候補数 n で点の分布が変わる）: 学習の候補は 128 固定、test の窓は 1〜数千。temperature を窓の大きさ（log n）で条件付けるのは 1 パラメータの追加で構造の変更。ただし較正は順位を変えないので、単独のモデルの MRR には効かない。合成（ranker）に渡す点の比較可能性だけに効く。後段の課題として記す。

### T4. 多タスクの頭
- FPNet は既に指紋の BCE と元素数（確認）。fragnn に「前駆体の式の元素数」「指紋の一部」を足すのは入力（断片の説明）から遠く、効きにくい。整列に指紋の頭を足すのは MSAlign の設計の外。**優先度低**。

### T5. 合成スペクトルでの事前学習（ICEBERG など）と S5
- 出典 6 の要点: 符号器ごと学習すると事前学習の差は消え、効くのは合成スペクトルで**分子の範囲**を広げること。この競技の 2・3 類（参照なし・新規）向け。
- 障害: ICEBERG/GLACIER は MassSpecGym で学習しており、こちらの検証の fold と構造が重なる可能性（glacier-iceberg-provenance.md）。論文は CC BY-NC-SA（確認）、重みのライセンスと再現性は未確認。生成は GPU が要る（MPS で数十万スペクトルは非現実的、目安）。
- 判断: 残り 3 週では**しない**（§6）。

### T6. EMA / SWA / 自己蒸留
- EMA（重みの指数移動平均）は値（減衰率）を 1 つ選ぶ必要があるが、0.999 のような慣例値を事前登録すれば調整ではない。fragnn・整列は「内部検証の損失が最良の 1 点」で、評価の間隔 2,000 ステップの揺れをそのまま持つ。EMA の重みを並べて評価するのは安い（学習 1 回の中で 2 本の重みを持つだけ）。
- SWA は学習率の規則（cyclic/定数）を変えるので、止め方の事前登録と衝突する。自己蒸留は学習を 2 回するので費用が倍。
- 証拠: 出典 7（未確認）。

### T7. fold・seed のアンサンブル
- 5-fold の検証を作れば、fold ごとのモデル 5 本がそのまま得られる。提出で 5 本の点を平均するのは「学習の方法」を変えずに分散を下げる最も確実な手（一般論）。検証での測り方は「fold k の評価には fold k を外して学習した 1 本しか使えない」ので、平均の効果は fold の中の seed 2 本の平均で代わりに測る（seed を 1 つ増やすだけ）。
- 費用: fragnn 10 h × 本数。MPS 1 台では fragnn の 5 本 × 2 seed は 3 週で無理。整列（軽い）と FPNet（4 h）なら可能。

### T8. 装置のカリキュラム・装置で条件付ける学習
- P8 (a) と同じ印を使い、学習の後半を timsTOF だけで微調整する案は、切り替えの時点を選ぶことになる。**P8 (a) で足りる**。

## 5. 上位 5（残り 3 週）

1. **P1: 学習から [2M…] の二量体を外す（3 本とも、まず整列と FPNet）** — test に 0%、train の timsTOF の 29%。前処理 1 行、構造の変更で値の選択が無い。
2. **P3 + P8(a): CE 欠測の印と timsTOF の印を入力に足す（fragnn・整列）** — FPNet に既にある形を写すだけ。test は常に CE あり・常に timsTOF。
3. **P4: 同じ分子の複数 CE の merge で学習（fragnn、p = 0.3 を FPNet から借りる）** — 推論の形（分子に 1 リスト）と学習を揃える。merge は FPNet で動いている。
4. **T7: fold のモデル 5 本の平均を提出の既定にする（FPNet・整列）、効果は seed 2 本で 1 回測る** — 5-fold の検証で副産物として得られ、追加の学習が少ない。
5. **P2: fragnn のピークを 32 → 64 本** — test のピーク数（中央値 230）に対して 32 本は少なすぎる。費用が大きいので、時間の上限の規則を Issue で先に確かめてから。

順の理由: 効果の大きさの証拠はどれも未測定なので、「test との不一致がデータで確かめられている」×「費用が小さい」×「調整の値が要らない」で並べた。1〜3 は 1 回の学習に 1 つの変更として、別々の Issue で事前登録する（まとめると効果が分けられない。分けると時間が足りないなら、1+2 を 1 本の「test の分布に合わせる」変更として事前登録し、それを単位に採否を決める）。

## 6. しないこと（理由）
- **合成スペクトルでの事前学習（ICEBERG/GLACIER）**: GPU が要る、MassSpecGym 由来で検証と重なる恐れ、重みのライセンス未確認、3 週で再現まで届かない。
- **強度の変換・top-k の値の比較・m/z の binning**: 値を選ぶ調整になる。binning は今の集合の表現からの後退。
- **部分式の付与（MIST 型）を fragnn に足す**: 同じ式の候補では区別に効かない。主な誤りは異性体の中。
- **focal/cosine 損失への置き換え**: listwise CE は MRR の目的に既に合っている。替える根拠の証拠が無い。
- **DANN・装置のカリキュラム**: 追加の値（逆勾配の重み・切り替え時点）が要り、不安定。P8 (a) の印で足りる。
- **SWA・自己蒸留**: 止め方の事前登録と衝突する、または費用が倍。
- **窓の大きさへの較正を単独のモデルで測る**: 順位を変えないので MRR に出ない。ranker の段の課題。
