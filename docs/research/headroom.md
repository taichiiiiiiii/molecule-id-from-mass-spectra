# 伸びしろの分解（#210、#195 A4・A5）

対象: #195 の A4（失点を型ごとに分け、直したときの MRR の上限と順位を出す）と A5（見える test の型の比率）。A11・A12 は PR #204（#203）の値を参照する。**PR #204 は完了レビューが 3 回 FAIL のため、その値は「レビュー未通過」として引く。**

## 1. 定義（計算の前に固定。#210 の本文と同じ。結果を見て変えない）

### 1.1 A4 の区分
- 対象: v3 の 4 集合（v3_c1〈C1 型〉・v3_c2〈C2 型〉・enveda_v1〈プールにあり参照なし〉・v3_c2n）と、A3a の合併集合（v3_c1u_t10・v3_c2_t10・enveda_v1u_t10・v3_c2nu_t10、#199・PR #200）
- 対照: `run.py --stages score,prior,frag` の出力 `submission_score+prior+frag.csv`（上位 25）。この縮小版の土台は LB 0.282 相当で、0.487 / 0.495 系統の提出とは違う（#195 A10）。ここで出す上限は**この土台の上の上限**である
- 照合: `scripts/validate/mrr25.py` の `to_key` / `truth_keys`（metric と同じ: 立体を外す → 互変異性体の正準化 → InChIKey14）
- 窓: `run.py` の `visible_window` と同じ（中心は `pc_logits.npz` の `__targets__`、±10 ppm、`pool=remove` の集合は `drop_keys.txt` の候補を除く）
- 窓の中に正解があるか: 窓の候補のうち、正解と重原子の組成（H と電荷を除く元素の数）が同じか組成が読めない候補の `to_key` を正解のキーと比べる（InChIKey14 が同じなら重原子の組成も同じなので漏れない）
- プールにあるか（窓の外も含む）: プールの `key`（scorer のキー）と正解の `score_key` の一致。隠した候補は「無い」として数える
- PubChem 層: `data/ext/pubchem_tier` の ±10 ppm の窓の SMILES。窓の中の判定は上と同じ。区分 (i) の分子だけを調べる
- 区分（分子ごとに 1 つ）:
  - (i-a) `i_pool_offwin`: 正解はプールにあるが窓の外
  - (i-b) `i_pubchem`: プールの窓に無く（プールにも無く）、PubChem 層の窓にある
  - (i-c) `i_none`: どちらの窓にも無い
  - (ii) `ii_below25`: プールの窓にあるが、対照の上位 25 に無い
  - (iii) `iii_rank2_25`: 対照の 2〜25 位
  - (iv) `iv_top1`: 対照の 1 位
- 上限: 区分の分子を全部 1 位にできたときの MRR の増え = Σ(1 − rr)/n。全区分の上限の和 ＋ 対照の MRR = 1 をコードで確かめる
- 対照の MRR が既存の値（v3_c1 0.8535・v3_c2 0.0000・enveda_v1 0.8376・v3_c2n 0.6284、合併集合 0.8878・0.0000・0.8513・0.6357）と 4 桁で一致しなければ止める（終了コード 2）

### 1.2 A5 の定義（見える test 400 分子）
- 「train の写しらしい」: 既存の `outputs/test_library_match.parquet`（`scripts/eda/library_coverage.py` の出力。各スペクトルを、同じイオンモード・同じ付加イオン・前駆体 ±10 ppm の train スペクトルと平方根強度の近似 cosine〈許容 0.01 Da〉で比べ、分子ごとに最大値）の `best_cos ≥ 0.99` の分子。見える test に正解は無いので、構造が train にあるかの代わりにこれを使う
- 「候補 DB（プール）にある」: (a) プールの ±10 ppm の窓（中心は `sub_test_fold0` の `__targets__`）の候補の数 (b) 写しらしい分子のうち、最良一致の構造（`best_key`、train の raw InChIKey14）がプールの窓の候補の raw InChIKey14 にある分子の数
- 割合には Wilson の 95% 区間を付ける
- **注意（先に書く）**: データのページは見える test を training dataset の例と書いている（#196 の数え直しで引用済み）。そのため「train の写しらしい」割合はほぼ自明に高く出る。**A5 の値は隠れテストの型の比率の推定には使えない。** 使うなら「隠れテストも見える test と同じ作り方」という強い仮定の上である
