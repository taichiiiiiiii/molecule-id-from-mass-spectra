  - (i-c) `i_none`: どちらの窓にも無い

  - (iii) `iii_rank2_25`: 対照の 2〜25 位
  - (iv) `iv_top1`: 対照の 1 位
- 上限: 区分の分子を全部 1 位にできたときの MRR の増え = Σ(1 − rr)/n。全区分の上限の和 ＋ 対照の MRR = 1 をコードで確かめる

### 1.2 A5 の定義（見える test 400 分子）
- 「train の写しらしい」: 既存の `outputs/test_library_match.parquet`（`scripts/eda/library_coverage.py` の出力。各スペクトルを、同じイオンモード・同じ付加イオン・前駆体 ±10 ppm の train スペクトルと平方根強度の近似 cosine〈許容 0.01 Da〉で比べ、分子ごとに最大値）の `best_cos ≥ 0.99` の分子。見える test に正解は無いので、構造が train にあるかの代わりにこれを使う

## 4. 1 位 0.552 との差はどの区分から来うるか（推測を含む）

数字の出どころ: 1 位 0.552・200 位 0.495 は Public の leaderboard の CSV（2026-11-22T01:08:03 の版〈`report_2026-11-22_noon.md`〉と 11/21 13:07 UTC の版〈`report_2026-11-21_night.md`〉。どちらも同じ値）。自分の最良の Public は 0.495（58594647、公開ノートの写し、`report_2026-11-23_noon.md`）。差は 0.057 で、Public の 1 分子の SE の目安 約 0.035（kaggle-improvement-loop の記録、約 125 分子）の 1.6 倍。

- 縮小版の土台（この文書の対照）は LB 0.282 相当（#42 の提出 58119572 は score+prior）。#42 では、v3 の区分の MRR の混合で LB 0.282 / 0.246 を同時に説明するには「どの段も届かない区分」が k=1 で 0.258 以上、k=2 で 0.156 以上要り、v3_c2 型の比は 0〜0.47 で絞れなかった。**推測**: 隠れテストには、縮小版が 0 点の区分（C2 型か、それに似た「正解がプールに無い」分子）がかなりの割合ある
- 0.479 版は PubChem チャネルを固定の差し込みで持つ（`run.py` の注: 0.479 版 cell 33 の merge と同じ規則）。0.495 系統が同じ規則かは、この文書では確かめていない（未確認）。手元の同じ規則は C2 型で 0.087（§2.2、11/07 の記録）で、チャネルだけの 0.418 との差は 0.33。**推測**: 隠れテストの C2 型の比を f2 とすると、振り分けを直したときの上限の目安は f2 × 0.33（f2 = 0.15 なら +0.05、差 0.057 と同じ大きさ）。並べ替え（iii）の自前の部品の測った効果は C1 型・enveda 型で +0.003〜+0.006（区間は 0 をまたぐ）で、(1 − f2) を掛けると 0.005 未満
- したがって、§3 の順位は f2 に依る。(i-b) の 0.0193 /日 と (iii) の 0.0010〜0.0026 /日 から、f2 がおよそ 0.07〜0.12 より大きければ (i-b) が先（f2 × 0.0193 > (1 − f2) × 0.0015〜0.0026 の解。**推測の上の計算**）。#42 の下限（届かない区分 ≥ 0.156〜0.258）がそのまま C2 型だとすると、この条件を満たす。ただし #42 の届かない区分が C2 型だという証拠は無い（参照の無い in-pool の分子や装置の違いでも説明しうる）
- 0.495 系統の上での区分の大きさは測っていない（#195 A10: 測る土台と出す土台の違い）。この文書の上限は縮小版の上の値で、0.495 系統の上では (iii) の失点はもっと小さい可能性がある

**次の自前モデルの対象（材料としての読み）**: 1 位は (i-b)＝候補の取得と振り分け（#195 B8）。ただし f2 の仮定の上で、この文書は対象の切り替えを決めない（#195 B8 のとおり、切り替えは A7 の工程表で決める）。fragnn v2 の判定（#196）は今の計画どおり行い、その結果で (iii) の見込みを置き直す。
