## 計算の形（#208 で固定）
- sd_k: `net_mde.json` の集合ごと・変種ごとの `sd_delta`（同じ対照の版と組にした過去の変種の分子ごとの Δrr の標準偏差）から、`n_changed = 0` の変種と `stale_excluded` の変種を除き、型ごとの**中央値（主）**・最小・最大
- n: v3_c1u_t10 394、enveda_v1u_t10 373、v3_c2nu_t10 394、v3_c2_t10 197（A3a の拡大後）
- 下限は**正規近似** L_k = 平均の差_k − 1.96·se_k、se_k = sd_k/√n_k（bootstrap の代わり。sd_k は既知として扱い、標本 sd の揺れは入れていない）
- 筋書き: (S1) δ は C1 型だけ、他は 0。(S2) δ は C1・enveda・v3_c2n の 3 型に同じ大きさ。C2 型は両方で 0
- **型の間は独立と仮定**（同じ変更を 4 集合で測るので実際には相関しうる。仮定）
- P(採用) = Φ(δ_C1/se_C1 − 1.96) × Π_{k≠C1} Φ((δ_k + 0.02)/se_k − 1.96)。モンテカルロ（seed 0・10 万回）を並べた

## 読み

- 今の規則で、**S1・δ = +0.02・主の値（sd 中央値）の採用の確率は 0.207（MC 0.209）で、50% 未満**。最大の sd では 0.067、最小の sd では 0.982
- 主の原因は C1 型の下限 > 0 ではなく（δ = +0.02 で 0.681）、**効果が 0 の型にかかる「95% CI 下限 ≥ −0.02」の条件**: 本当に 0 の型でも、下限が −0.02 を上回るには平均の差が −0.02 + 1.96·se（se ≈ 0.008〜0.011 なので ≈ −0.004〜+0.001）以上である必要があり、enveda 型で 0.663、v3_c2n 型で 0.459 しか通らない。このため δ = +0.05 でも S1 は 0.304 で止まる
- δ = 0（第 1 種の過誤）は 0.008（C1 型単独の 0.025 以下）
- S2（3 型に同じ効果）では +0.02 で 0.652

## 規則の作り直し（1 案だけ、オーナーの承認まで保留）

S1・δ = +0.02 の主の値が 50% 未満なので、#195 A8 の決まりに従い 1 案だけ出す（検出力の表と n だけから導いた。他の案と比べて選んでいない。過去の実験の結果は見ていない・計算していない）。

- **提案 R1（今の規則との違い 1 行）: C1 以外の型の条件を「95% CI 下限 ≥ −0.02」から「平均の差（点推定）≥ −0.02」に変える。v3_c1u_t10 の下限 > 0 は変えない**
- 導き方: 上の表で検出力を落としているのは効果 0 の型の CI 下限の条件で、se が 0.008〜0.011 の n では「害が −0.02 より小さい」ことを CI で示すには効果 0 の型にほぼ正の点推定を求めることになる。「主集合 1 つ＋他は害なし」（#195 A8 の例）の「害なし」を、CI ではなく点推定で読む形にした
- R1 の検出力（同じ計算、上の「提案 R1」の表）: S1・+0.02 で 0.654（最小 sd 0.994・最大 sd 0.399）、S2・+0.02 で 0.681、δ = 0 で 0.024
- **R1 で手放すもの**（害の筋書きの表）: C1 に +0.02、他の 1 型に本当の −0.02 の損がある変更を、今の規則は 0.008〜0.011 の確率でしか採用しないが、R1 は 0.33〜0.34（主の sd）で採用する。−0.02 より小さい損は R1 でも止められない。−0.02 の損を許す線は今の規則と同じで、変えたのは「その線を CI で示すか、点推定で見るか」だけ
- 扱い: 採用はオーナーの承認まで保留。fragnn v2 の判定は #196 (f) に従う（承認が判定の前にあれば R1 で、無ければ今の規則で）。過去の不採用は覆さない

## 限界
- 正規近似（bootstrap ではない）、sd_k を既知とした、型の間の独立は仮定。sd_k は拡大前の集合の過去の変種の値
- 「本当の効果」は集合の型ごとの母平均の差であり、隠れテストでの効果ではない
