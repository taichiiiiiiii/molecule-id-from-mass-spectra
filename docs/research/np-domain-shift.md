## 0. 結論（先に）

- 隠れテストに当たる「timsTOF の問い合わせ × 天然物の正解」の組は、train の timsTOF の側にほとんど無い。dev の fold 1〜4 では、timsTOF のスペクトルを持つ構造 146,358 のうち天然物（v2 プールの COCONUT、src 2/3）は 42（0.03%）だった。fold 0 では 36,583 のうち 9。出典は `docs/research/np-subset-counts.json` の `fold_counts`（#300）。dev の評価で天然物の正解を十分な数だけ持つのは型 b（他の装置の問い合わせ、279 分子）だけ。その型 b での版 A の差は +0.0096 [−0.0108, +0.0293] で、0 を含む（同じ JSON の `cand3_vs_ctrl3`）
- 文献でも、合成の標準品で決めた手法の順位が天然物で逆になる例がある。ICEBERG の論文（S3）の検索 top-1 では、NIST20 の SCARF 0.184・NEIMS (FFN) 0.106 が、NPLIB1（GNPS の天然物）では SCARF 0.112・NEIMS (FFN) 0.212 になっていた。この論文で両方の領域の首位だったのは、構造から断片を作る模型（ICEBERG）だけだった。ただし模型はデータごとに学び直していて、偽物の集合も違う（同じ模型を領域の間で移した比べではない）。構造で分けた（scaffold）検証での落ち方も、学習した模型の中では ICEBERG がいちばん小さかった（NIST20 の cosine: ICEBERG 0.707 → 0.691、NEIMS (FFN) 0.614 → 0.548。学習しない CFM-ID は 0.371 → 0.401 で上がった）
- したがって、dev の型 a・c・d・e で出た伸び（合成の正解）が天然物の正解に同じ符号で移る根拠は、文献にも自前の記録にも無い。12/6 の判定の後に、天然物の側で伸びが出たのかを、規則の外の「記述の行」として別に書く（§4、規則は変えない）
- coltondowning のノートの主張との比べ（§3）: 「見える test は train の写し」は自前の記録と合う（400/400）。cosine の中央値 0.853 / 0.532 と類縁体の Tanimoto 約 0.33 は、自前の記録に同じ定義の値が無い。近い量だけを並べた。ノートには 0.853・0.532・0.33 を出すコードが入っていない（表だけ）ので、主張は未検証のまま
- 新しく見つけたリスク（§5 の F2-0）: 天然物らしさの点 `np_score`（#240 の自前の分類器）とその相対化の 5 列は、版 A の 81 列に入っている。dev の型 a・c・d・e では正解がほぼすべて合成（天然物 0〜0.5%）で、偽物の候補には COCONUT 由来の候補が入りうる（窓の中の数は数えていない）。ランカーが「天然物らしい＝偽物」を覚えていると、隠れテストの天然物の正解が下がる。dev では生の 2 列を外しても差は 0 付近だった（exp006 − exp003、64 列の土台、1 seed）。ただしこの比べは、dev の型 a・c・d・e の正解がほぼ合成なので、天然物の正解に対する影響を映せない。測り方は §5 に書いた

**S4. Kretschmer ほか「Coverage bias in small molecule machine learning」**（Nat. Commun.、2025-01-09 公開、DOI 10.1038/s41467-024-55462-w、https://www.nature.com/articles/s41467-024-55462-w ）

## 2. 自前の状況への当てはめ

- 化学のずれ（記録の数）:
  - train の timsTOF のスペクトルを持つ構造のうち天然物（COCONUT）は fold 1〜4 で 42 / 146,358、fold 0 で 9 / 36,583（`np-subset-counts.json` の `fold_counts`）。公式のデータのページは enveda-180 を「合成の薬らしいスクリーニング化合物で、test の分子とは化学空間が違う」と書いている（日報 2026-11-28 昼 Q1）
  - dev の正解の天然物の割合（exp003 の 3,901 分子）は a 4/789・b 787/787・c 0/788・d 0/745・e 2/792（同じ JSON の `np_count_by_type`）。型 b の天然物 100% は集合の作り方（select_c2p・src 3）から来る
  - timsTOF の問い合わせで正解が天然物の分子は、既存の集合と MSG を除くと fold 1〜4 の和で 34、fold 0 で 5。#300 で事前に決めた 150 に届かないので、新しい集合は作らない（#300 の決定）
- 伸びが移るか（記録の数）: 版 A − 対照（3 seed 平均）は a +0.0149 [+0.0044, +0.0260]・b +0.0096 [−0.0108, +0.0293]・c +0.0943・d +0.0066 [+0.0006, +0.0129]・e +0.1196（`np-subset-counts.json` の `cand3_vs_ctrl3`、型 b は 279 分子）。天然物の正解が多い唯一の型 b では、95% 区間が 0 を含む。ただし型 b は問い合わせの装置（timsTOF 以外）と正解の参照の扱いも型 c・e と違うので、「化学のせい」とは切り分けられない
- 文献との対応:
  - S3: 合成の標準品で決めた手法の順位は、天然物で逆になりうる。自前の dev の型 a・c・d・e は「合成の正解で決めた順位」にあたる
  - S2・S5・arXiv:2611.28096: 2D の構造が違うだけで分けると近い重複が残り、成績を高く見積もる。B8 の fold は構造で分けていて、MCES の距離は保証していない（`neighbour-density-transfer.md` §1.1）
  - S4: 学習に無いクラスは評価にも出ないので気づけない。隠れテストの天然物のクラスが dev に無ければ、dev の値はそこについて何も言わない
  - arXiv:2611.28096 の介入: 近い学習の構造を除くと、成績は大きく落ちる（R@1 29.6% → 4.9%）
  - S3: random → Murcko scaffold split で学び直すと、学習した模型の cosine は 0.016〜0.066 落ちる（ICEBERG 0.707 → 0.691 が最小、NEIMS (FFN) 0.614 → 0.548 が最大）。学習しない CFM-ID は 0.371 → 0.401 で上がる。近い構造を除く介入ではなく、分け方を変えた比べ
- 縮小版の Public（0.282・0.246・0.247）が dev の MRR よりずっと低いことは、このずれと合う。ただし提出の構成が dev の比べと同じ条件ではないので、ずれが原因だとは示せていない（日報 Q1 の注意のとおり）

## 4. #300 の内訳（天然物 / それ以外）で測る案と読み方

**どの案も、#249 の採否の規則・#282 の関門・列・定数・seed を変えない。** 下の読みは記述とリスクの記録だけに使い、版 A の群の採否や最終の選び方の規則には入れない。定義は数える前に Issue に固定し、1 回だけ数える。

- **M1（12/6 の判定の記録に足す記述の行）**
  - 中身: #300 の `np_subset_counts.py` と同じ定義で、判定の候補（版 A）− score+prior の差を「正解が天然物 / それ以外」に分けて書く。判定用 4 集合では v3_c2nu_t10 だけが天然物（394/394、MSG を除くと 167）で、他の 3 集合は天然物の正解が 0〜1（所属の数だけ。出典は日報 2026-11-28 昼 Q1 の v3_c1u_t10 1/394・enveda_v1u_t10 0/373・v3_c2_t10 0/197・v3_c2nu_t10 394/394、と `docs/experiments/holdout_msg_lists.json` の v3_c2nu_t10 の n_remain 167）。したがって集合の単位の内訳がそのまま天然物 / それ以外になる。新しい集合は作らない（#300 の決定）
  - 読み（規則の外、事前に固定）: 判定を規則どおりに読み終えた後に書く。v3_c2nu_t10（天然物）の下限 ≤ 0 で、ほかの集合の下限 > 0 なら、「天然物の側への移りは示せない」とリスクに記録する。dev の型 b（+0.0096 [−0.0108, +0.0293]）とあわせて最終の 2 本の説明に書く。判定の合否は変えない
  - 交絡（事前に書く）: v3_c2nu_t10 と型 b は、天然物であることのほかに、問い合わせの装置・参照の隠し方・MSG との重なりの除き方が他の集合と違う。化学のせいとは切り分けられない
- **M2（dev: 天然物らしさの連続の点で層に分ける）**
  - 理由: COCONUT への所属で分けると、型 a・c・d・e の天然物の側は n < 30 になる（#300）。自前の天然物らしさの分類器（#240、fold k のモデルは fold k の構造を学習に含まない。`pred_dev.parquet` の model_fold = query_fold）の正解の行の点 `np_score` なら、すべての型で層を作れる
  - 定義（案）: 型ごとに、正解の行の `np_score` の 3 分位（境は正解の行から）で 低・中・高、正解が候補に無い分子は「欠け」。差 = 版 A の 3 seed 平均 − 対照 exp007・014・015 の 3 seed 平均。区間は層の中の分子の対応つき bootstrap（2,000 回、seed 0）。`scripts/research/n1_density_strata.py`（#292）と同じ形で、列の名前だけを替える
  - 読み（案）: 型の全体の下限が > 0 なのに「高」の層の下限が ≤ 0 なら、「天然物らしい正解への移りは示せない」とリスクに記録する。層の間の差の検定はしない
  - 限界: `np_score` は版 A の入力の列でもある。入力の列で層に分けるので、層の差には「その列をランカーがどう使ったか」が混ざる。合成の正解の中での天然物らしさで、天然物そのものではない
- **M3（dev: 正解が学習の近い重複に頼っていないか）**
  - 中身: dev の正解の構造ごとに、他の fold（そのランカーの学習に使った fold）の構造と train の構造への Morgan（半径 2・2,048 ビット）の最近傍 Tanimoto を数える（構造だけでラベルは使わない）。≥ 0.85（S2 の「近い重複」の線、文献の値をそのまま使い、選び直さない）の分子を除いた残りで、版 A の差を型ごとに書く
  - 読み（案）: 除いた残りでも型の下限が > 0 なら「近い重複に頼っていない」。≤ 0 になる型はリスクに記録する
- **M4（ラベルを使わない: 隠れテストに近い化学が train からどれだけ遠いか）**
  - 中身: enveda-np-examples の構造（split np、265 構造。#300 の `fold_counts` の `np`。質量の段 ② の後の 244 のうち 220 が MSG と重なる）と、dev の正解の構造それぞれについて、train の構造への最近傍の Tanimoto の分布を、同じ指紋・同じ除外で並べる（`two-stage-audit` の `nn_similarity_strata.py` と同じ量）
  - 読み（案）: 天然物の例の分布が dev の正解より低い側に寄っていれば、隠れテストは dev の「近傍の少ない層」より外側にいる。#292 の層別のうち低い層の値を重く読む根拠になる（記述だけ。重みは付けない）

## 5. F2: ずれに強い入力・学習の候補（測り方つき）

どれも構造の変更か、測ることだけ。既存の定数（窓 ±10 ppm・K_KEEP 60・PC_N1 5,000・H3 の α・β など）は選び直さない。ハイパラは LightGBM lambdarank の既定値のまま。版 A に入れるかどうかは、今までどおり #282 の dev の関門（3 seed の平均、5 型すべてで点推定 ≥ −0.02）で決める。そのうえで M2 の層別を記述として足す。

- **F2-0（リスクの点検。最初にやる）: `np_score` が「天然物らしい＝偽物」の近道になっていないか**
  - 理由: スキルの注意「訓練で偽物だけが占める領域は、学習された罰になる」と同じ形。型 a・c・d・e の正解はほぼ合成で、COCONUT 由来の偽物の候補が窓に入りうる。版 A の列は `np_score` と相対化の 5 列（`has_np` は dev で定数）。生の 2 列を外しても dev の差は 0 付近だった（exp006 − exp003（64 列の土台、版 A ではない）、seed 0 の 1 本、seed の揺れは測っていない: a −0.0016 [−0.0085, +0.0050]・b −0.0019・c −0.0096 [−0.0210, +0.0019]・d −0.0020・e +0.0019、`docs/experiments/error-analysis-2026-11-26.md` §1）。ただし相対化の 5 列は残した比べで、dev の正解はほぼ合成なので、天然物の正解への影響は dev では見えない
  - 測り方（案）: (1) 型ごとに、正解の行と偽物の行の `np_score` の分布（中央値・10/90% 分位）と、「`np_score` ≥ q のときの正解の割合」を数える（dev はラベルを見てよい）。(2) 反事実: 型 a・c・d・e の正解の行の `np_score` を、同じ窓の COCONUT の候補の中央値に置き換え、相対化の 5 列も同じ式で計算し直したときの top-1 の率の変化（定義は repo のコードに書いてから数える）。(3) 大きく下がるなら、構造の変更として「`np_score` の 6 列を外す」か「型 b を含む学習の行の比率を固定する」（比率は値を 1 つだけ事前登録し、選び直さない）を、事前登録して #282 の関門で測る
- **F2-1: 断片の証拠の群（GLACIER・MetFrag-lite・mf_*）が天然物らしい層で効いているか**
  - 理由: S3 では断片を作る模型が、天然物の側でも、構造で分けたときにも、いちばん崩れにくかった
  - 測り方（案）: 既存の群の抜き取り（exp004〜006 と同じ `feature_groups.py` の形、−M 群・−GLACIER 群）を、M2 の層ごとに書く。新しい列は作らない
- **F2-2: ライブラリの化学に頼らないスペクトルの埋め込み（DreaMS）による近傍の照合**
  - 理由: S5 はラベルの無いスペクトルで事前学習していて、表現がライブラリの化学に頼らない、と著者は書く。N1（`nbr_ms_mean`）は MS2DeepScore 型の近傍の類似度。公式の `ssl_model.ckpt` の使用は可（`rules-and-deps.md`）。ただし自前の埋め込みの生成コードは main に無い
  - 測り方（案）: 生成コードを main に入れてから、N1 と同じ「化学的に近い 10 個」の近傍で DreaMS の cosine の平均を 1 列足す。#282 の関門と M2・M3 の層別で測る。時間は B5 の関門に足す（未測定）
- **F2-3: train の統計から作った列（事前の点・人気度など）が天然物の側で逆に効いていないか**
  - 理由: S4 は、測られた化合物の選び方が値段や入手しやすさで偏り、学習データの偏りになると書く。自前の事前の点は train（enveda-180 が多い）の頻度から作るので、合成の化学の偏りをそのまま持つ
  - 測り方（案）: 該当する群（`competition-playbook.md` の (c) の定義にある、train の統計の列）を抜き取り、M2 の層と型 b に分けて書く
- **F2-4: ランカーの学習の分け方を、近い重複が fold をまたがない形にする**
  - 理由: S2（MCES < 10）・S5（Murcko ヒストグラム）。B8 の fold は構造で分けているだけで、近い重複が fold をまたぐ。ランカーの leave-one-fold-out の学習と評価が近い重複で甘くなっている可能性がある
  - 測り方（案）: まず M3 で、近い重複を除いた残りの差を数える。差が大きく下がるときだけ、fold の境を変えた dev の作り直しを、別の Issue で事前登録する（12/6 の判定用 holdout は変えない）
